# Synapse Primer

Minimalist dark React/Tailwind prototype with four focus-oriented modules:

- Visual Stim: moving target pursuit/catch task.
- Friction Task: 60-second Stroop task with Focus Score.
- Vagal Pacer: 4-4-4-4 CSS breathing animation.
- Sonic Precision: Web Audio oscillator sweep with keyboard identification and adaptive staircase.

## Run

```bash
npm install
npm run dev
```

The Sonic Precision module uses the browser's Web Audio API and requires a user gesture before audio can play.
