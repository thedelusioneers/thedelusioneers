Line Item 3 — The Rule
The Rule
CRTC Internet Code — Telecom Regulatory Policy 2019-269, in force
Providers must give advance written notice before implementing a price change.
The Internet Code specifies that notice must be in writing.
The Internet Code does not specify where within a billing statement that notice must appear.
Notice was given. Whether notice was findable is a question the Internet Code does not resolve.
