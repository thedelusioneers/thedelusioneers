# THREAD COPY SPEC
Compiled from SOP v1.1, Deliverable 4.

## Platforms
- Primary: Threads. Secondary: Bluesky.
- HARD LIMIT: 300 characters per post (Bluesky ceiling). Count, don't estimate.
- Typical length: 8–12 posts.

## Architecture
- POST 1: Hook — the finding in two sentences, no windup.
- POST 2: Frame — what kind of piece this is, what it covers.
- POSTS 3–N: One post per mechanism/section (hook line + instrument citation).
- POST N+1: Rhyme or key structural finding.
- POST N+2: Summary figures (the ledger line).
- FINAL: CTA — links to HTML artifact and source page.

## Image pairing (distribution-desk applies these)
- Cover card pairs with final CTA post (or post 1).
- Each mechanism card pairs with its mechanism post.
- Summary card pairs with summary figures post.
- NEVER attach images to the hook post — text performs better cold.

## Hashtags and links
- Hashtags: final post only, 2–4 max.
  Standard: #Ontario #CanadianPolitics #Accountability (swap #Ontario for the
  piece's jurisdiction when federal). One piece-specific tag allowed.
- Links: final post only. Both HTML artifact and source page.
- [link] placeholders until final URLs exist in the assignment brief.
